# E-Commerce Database Project (SQL Server)

## Overview

This project consists of designing and querying a relational database for an e-commerce system.

The database contains 8 related tables:

- Customers
- Cities
- Provinces
- Countries
- Products
- Product Descriptions
- Invoices
- Invoice Details
